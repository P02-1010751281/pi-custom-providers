# v0.3.x/v0.4.1 → v0.5.0 模型合成差分（2026-10-03）

**结论**：对「目录 + 基底表 + 端点 + 第 3/4 层」这组场景，v0.5.0 与 `v0.4.1` 的注册结果只有
**5 处**差异（含复核 2 的 S8：第 3 层 `models[]` 停读），每一处都对应一条已声明的破坏性变更，没有意外漂移；我这次加的 compat 报告
（`5eb333d`）对合成输出是**零差分**（只多警告行）。

## 怎么跑（跨检出差分）

模型合成是纯函数段（`directory.ts` → `providers.ts synthesizeModels` → `stubPi` 收到的
`providers` Map），所以把同一组场景喂给两个检出、比较注册结果即可；不碰网络、不依赖命令面
（命令面在 v0.4.1/v0.5.0 是两套，比它会淹掉合成差异）。

```bash
git worktree add /tmp/v041 v0.4.1           # 旧版检出
git worktree add /tmp/prev <v0.5.0 上一个提交>  # 例：8376384
node /tmp/diff/runner.mjs /tmp/v041          > /tmp/diff/v041.json
node /tmp/diff/runner.mjs /tmp/prev          > /tmp/diff/prev.json
node /tmp/diff/runner.mjs "$PWD"             > /tmp/diff/head.json
diff -u /tmp/diff/v041.json /tmp/diff/head.json   # 旧 → 新
diff    /tmp/diff/prev.json /tmp/diff/head.json   # 有改动的那一步
```

场景（`runner.mjs` 逐条写明）：两端点 vendor（`scnet`）、默认协议翻转（`relay`，`api`+`baseUrl`）、
provider 级 `compat`（`cmdc`）、第二账号（`cmdc/accounts.json` + `providers.cmdc-work`）、
旧 key 别名块（`codecommand`）、`modelOverrides`（pi 最高层，两版都不自己应用）、
以及一个 pi 会拒的 `models[]` 补丁块（`relay2`）。输出规范化到
`{ provider: { config: {api, baseUrl, authHeader, compat, headers}, models: [id, name, api, baseUrl, reasoning, contextWindow, maxTokens, input, compat, headers] } }`，按 id 排序。

## 结果

`prev → head`：**完全一致**（compat 报告只新增 warning，`apis.ts`/`providers.ts` 不动合成）。

**复核 2（2026-10-03，`models[]` 停读之后）**：给 runner 补上 **S8**（注册 id 下的**合法** `models[]` 补丁）后，`8376384 → HEAD` 只差一处：`commandcode` 的 `cc-1` 从 `name=REGISTERED-PATCH / maxTokens=777 / 带 api+baseUrl` 回到表里的 `cc-1 / 8000 / 无 api`——第 3 层不再被读作模型补丁。

**教训**：S8 之前的 7 个场景都没覆盖「注册 id 下的合法 `models[]` 补丁」这个形状，所以那次复核是零差分——**零差分不等于零行为变更**；行为变更要先把对应形状写进场景，再跑差分。

**复核（2026-10-03，孤儿块警告 `b12183d` 之后）**：`8376384 → 2ebb769` 再跑一次仍是零差分
（`prev.json`/`head.json` 各 2515 B，`diff` 无输出）——`config.ts orphanProviderBlocks` 只往
共享 issue 列表加 warning，合成算法与注册结果都没碰。

`v0.4.1 → v0.5.0`：4 处，逐条归因：

| 差异 | 场景 | 归因 |
|---|---|---|
| `scnet`/`commandcode` 的 `config.authHeader: true` 消失 | 这两个目录都没有 `accounts.json` | **出厂默认账号已删**（`DEFAULTS`/`defaultAccount`/`envVar`，v0.5.0 破坏性变更）。v0.4.1 由出厂层给出 `{id: scnet, envVar: SCNET_API_KEY, authHeader: true}`；现在凭据只剩 `accounts.json` 一个家 ⇒ 升级动作：给这类目录写 `accounts.json`（本机 `scnet/` 就是这一条） |
| `commandcode` 的 `cc-1` 不再被 `providers.codecommand` 块改（`name` 仍 `cc-1`、`maxTokens` 8000 而非 `OLD-KEY`/777） | 别名 key 下的合法 `models[]` 补丁 | **#18 B′**：别名 key 不再是配置层（`providerLayerFor` 只查注册 id）。旧 key 要改成 `providers.commandcode` |
| `relay2` 整个 provider 消失（v0.4.1 里它带着 `maxTokens: 42` 注册） | `providers.relay2.models=[{id,maxTokens}]`（无 `api`/`baseUrl`） | **#22/#23 预报告**：真实 pi 对这两个字段缺失会抛 `no "api" specified` / `"baseUrl" is required…`，v0.4.1 的 stub 掩盖了这一点（真机上旧版同样注册不上）；HEAD 报错并跳过该 provider。**旧版那一行是桩的产物，不是 v0.5.0 的回退** |
| 其余全部一致（两协议 stamping、端点/baseUrl 解析、基底 ⊕ 补丁、provider 级 `compat` 折算、第二账号 id、`modelOverrides` 不动） | 全部场景 | 预期：v0.5.0 只改配置层的**读取范围**，不改合成算法 |

## runner 源码

```js
/**
 * Model-synthesis differential: run one scenario set through a checkout of this repo's extension
 * and print what it would register, canonically. Usage: node runner.mjs <repo-root>
 */
import { mkdirSync, mkdtempSync, writeFileSync } from "node:fs";
import os from "node:os";
import path from "node:path";
import { pathToFileURL } from "node:url";

const root = process.argv[2];
const agent = mkdtempSync(path.join(os.tmpdir(), "pi-diff-"));
process.env.PI_CODING_AGENT_DIR = agent;

const dir = (id) => {
	const d = path.join(agent, "custom-providers", id);
	mkdirSync(d, { recursive: true });
	return d;
};
const write = (file, value) => writeFileSync(file, `${JSON.stringify(value, null, "\t")}\n`);

const model = (id, extra = {}) => ({
	id,
	name: id,
	reasoning: false,
	input: ["text"],
	contextWindow: 100000,
	maxTokens: 8000,
	cost: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0 },
	...extra,
});

// S1/S5 — a two-endpoint vendor with a table, plus an alias-key block (the known B′ diff).
write(path.join(dir("scnet"), "provider.json"), {
	name: "SCNet",
	api: "openai-completions",
	baseUrl: "https://api.scnet.cn/api/llm/v1",
	modelsPath: "/models",
	apis: { "anthropic-messages": { baseUrl: "https://api.scnet.cn/api/llm/anthropic", modelsPath: "/v1/models" } },
});
write(path.join(dir("scnet"), "models.json"), { models: [model("m-default"), model("m-anthropic", { api: "anthropic-messages" })] });

// S2/S7 — a vendor with a model table and (later) a provider block that flips the default api.
write(path.join(dir("relay"), "provider.json"), { name: "Relay", api: "openai-completions", baseUrl: "https://relay.example/v1", modelsPath: "/models" });
write(path.join(dir("relay"), "models.json"), { models: [model("m-relay")] });

// S3/S4/S6 — a vendor with two accounts and provider-level compat.
write(path.join(dir("cmdc"), "provider.json"), { name: "Command Code", api: "openai-completions", baseUrl: "https://cmdc.example/v1", modelsPath: "/models", apis: { "anthropic-messages": { baseUrl: "https://cmdc.example" } } });
write(path.join(dir("cmdc"), "models.json"), { models: [model("c-default", { reasoning: true }), model("c-anthropic", { api: "anthropic-messages" })] });
write(path.join(dir("cmdc"), "accounts.json"), { default: "main", main: { apiKey: "$CMD_API_KEY" }, work: { apiKey: "$CMD_API_KEY", authHeader: true } });

write(path.join(agent, "models.json"), {
	providers: {
		// S2: a legal default-protocol flip (api + baseUrl).
		relay: { api: "anthropic-messages", baseUrl: "https://relay.example/anthropic" },
		// S3: provider-level compat, folded onto the models of the effective default protocol.
		cmdc: { compat: { thinkingFormat: "zai", supportsTemperature: false } },
		// S4: a config block for the second account, by its registered id.
		"cmdc-work": { baseUrl: "https://cmdc.example/v1-alt" },
		// S5: an alias-shaped key (not a registered id) carrying a model patch.
		"scnet-openai": { models: [{ id: "m-default", name: "ALIAS", maxTokens: 12345, api: "openai-completions", baseUrl: "https://api.scnet.cn/api/llm/v1" }] },
		// S6: pi's own top layer — neither version applies it; pi does.
		// (added below, on its own provider block)
		"cmdc-overrides": {},
	},
});
// S6 needs its own block; keep `cmdc` free of it so S3's compat stays visible.
write(path.join(agent, "models.json"), {
	providers: {
		relay: { api: "anthropic-messages", baseUrl: "https://relay.example/anthropic" },
		cmdc: { compat: { thinkingFormat: "zai", supportsTemperature: false }, modelOverrides: { "c-default": { name: "OVERRIDDEN" } } },
		"cmdc-work": { baseUrl: "https://cmdc.example/v1-alt" },
		"scnet-openai": { models: [{ id: "m-default", name: "ALIAS", maxTokens: 12345, api: "openai-completions", baseUrl: "https://api.scnet.cn/api/llm/v1" }] },
		// S5b: the vendor's former key, still carrying a legal patch.
		codecommand: { models: [{ id: "cc-1", name: "OLD-KEY", maxTokens: 777, api: "openai-completions", baseUrl: "https://api.commandcode.ai/provider/v1" }] },
		// S8: a *legal* model patch under the registered id — a model entry that could be a new
		// model to pi (api+baseUrl present), read by v0.4.1/v0.5.0-prev as a patch and dropped
		// once the config layer stopped being a home for model content.
		commandcode: { models: [{ id: "cc-1", name: "REGISTERED-PATCH", maxTokens: 777, api: "openai-completions", baseUrl: "https://api.commandcode.ai/provider/v1" }] },
		// S7: an illegal model patch (pi throws on it at registration).
		relay2: { models: [{ id: "r2-1", maxTokens: 42 }] },
	},
});

// S5b — the same vendor under its *old* key (`codecommand`, a v0.4.1 alias of `commandcode`).
write(path.join(dir("commandcode"), "provider.json"), { name: "Command Code", api: "openai-completions", baseUrl: "https://api.commandcode.ai/provider/v1", modelsPath: "/models" });
write(path.join(dir("commandcode"), "models.json"), { models: [model("cc-1")] });

// S7 — a `models[]` block pi rejects (no `api`, no `baseUrl`): v0.4.1 applied it as a patch,
// HEAD reports it and leaves the provider unregistered — which is what real pi does (it throws).
write(path.join(dir("relay2"), "provider.json"), { name: "Relay 2", api: "openai-completions", baseUrl: "https://relay2.example/v1", modelsPath: "/models" });
write(path.join(dir("relay2"), "models.json"), { models: [model("r2-1")] });

const harness = await import(pathToFileURL(path.join(root, "tests/harness.mjs")).href);
const factory = (await harness.loadTs("extensions/custom-providers/index.ts")).default;
const { pi, providers } = harness.stubPi();
await factory(pi);

const pick = (row) => {
	const out = {};
	for (const key of ["id", "name", "api", "baseUrl", "reasoning", "contextWindow", "maxTokens", "input", "compat", "headers"]) {
		if (row[key] !== undefined) out[key] = row[key];
	}
	return out;
};
const canonical = {};
for (const [id, config] of [...providers.entries()].sort()) {
	canonical[id] = {
		config: { api: config.api, baseUrl: config.baseUrl, authHeader: config.authHeader, compat: config.compat, headers: config.headers },
		models: (config.models ?? []).map(pick).sort((a, b) => String(a.id).localeCompare(String(b.id))),
	};
}
console.log(JSON.stringify(canonical, null, 1));
```
